# Анализ метрик маркетплейса

📌 **Цель проекта:**  
Выявить причины стагнации выручки и найти точки роста через анализ пользовательского поведения на маркетплейсе по продаже товаров из Бразилии.

---

## 📊 Данные

Для анализа метрик маркетплейса использовались несколько таблиц, содержащих информацию о пользователях, заказах и товарных позициях.  

---

### Таблица **olist_customers_dataset.csv**  
Содержит информацию о пользователях маркетплейса.  

**Поля:**
- **customer_id** — позаказный идентификатор пользователя.  
- **customer_unique_id** — уникальный идентификатор пользователя.  
- **customer_zip_code_prefix** — почтовый индекс пользователя.  
- **customer_city** — город доставки пользователя.  
- **customer_state** — штат доставки пользователя.   

---

### Таблица **olist_orders_dataset.csv**  
Содержит данные о заказах на маркетплейсе.  

**Поля:**
- **order_id** — уникальный идентификатор заказа (номер чека).  
- **customer_id** — позаказный идентификатор пользователя.  
- **order_status** — статус заказа (подробный список см. ниже).  
- **order_purchase_timestamp** — время создания заказа.  
- **order_approved_at** — время подтверждения оплаты.  
- **order_delivered_carrier_date** — время передачи заказа в логистическую службу.  
- **order_delivered_customer_date** — время доставки заказа покупателю.  
- **order_estimated_delivery_date** — обещанная дата доставки.  

**Уникальные статусы заказов:**
- `created` — заказ создан;  
- `approved` — подтверждён;  
- `invoiced` — выставлен счёт;  
- `processing` — в процессе сборки;  
- `shipped` — отгружён со склада;  
- `delivered` — доставлен пользователю;  
- `unavailable` — отменён (товар недоступен);  
- `canceled` — заказ отменён.  

---

### Таблица **olist_order_items_dataset.csv**  
Содержит товарные позиции, входящие в заказы.  

**Поля:**
- **order_id** — идентификатор заказа.  
- **order_item_id** — идентификатор позиции внутри заказа.  
- **product_id** — идентификатор товара.  
- **seller_id** — идентификатор продавца.  
- **shipping_limit_date** — крайний срок передачи товара в логистику продавцом.  
- **price** — цена товара за единицу.  
- **freight_value** — стоимость доставки.  

---

## 🔍 Что сделано
- Провёл когортный анализ **retention** в оформлении заказов  
- Проанализировал временные метрики и статусы заказов, определил узкие места в процессе доставки  
- Оценил наличие **product/market fit** на основе доли возвращающихся и платящих пользователей  
- Сформулировал ключевые бизнес-метрики: **LTV, CAC, Retention, CR, AOV**  
- Приоритизировал гипотезы по фреймворку **ICE** и выбрал наиболее перспективную для роста выручки  
- Подготовил визуализации и презентацию выводов для продуктовой команды
